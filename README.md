# Book Tracker - Трекер прочитанных книг

## Автор
Щербаков Дамир

## Описание программы
Desktop-приложение для учета прочитанных книг с возможностью фильтрации, статистики и сохранения данных. Создано с использованием Python и Tkinter.

### Возможности:
- 📚 Добавление книг с указанием названия, автора, жанра и количества страниц
- 🔍 Фильтрация по жанру и количеству страниц (>200, ≤200, >300, ≤300)
- ✏️ Редактирование книг по двойному щелчку
- 🗑️ Удаление книг
- 📊 Детальная статистика (по жанрам, авторам, общая)
- 💾 Автоматическое сохранение в JSON
- ✅ Валидация ввода данных
